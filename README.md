📦 Supply Chain Inventory Optimization Project
This project is a data-driven exploration of inventory optimization techniques within a supply chain context. Using Python and common data science libraries, it demonstrates how businesses can balance service levels and inventory costs through simulation and modeling.

📑 Project Overview
The notebook includes:

Data exploration and visualization of supply chain inventory metrics.

Demand forecasting using statistical or machine learning techniques.

Inventory policy modeling (e.g., EOQ, (Q,R) models).

Optimization using simulation or mathematical programming.

Evaluation of service levels and cost trade-offs.

🛠️ Technologies Used
Python 3.x

Jupyter Notebook

Pandas

NumPy

Matplotlib / Seaborn
